# Dépann’toi Tél — Aperçu partagé

Site statique public de démonstration de la mallette de diagnostic CIVIA.

- Aucun accès au PC Maître, ADB, fichiers privés ou modem.
- Aucune API ni serveur de diagnostic accessible.
- Version d'aperçu en lecture seule ; les données d'exemple sont exclusivement des informations techniques d'un cas de réparation connu.
- Les modifications ne deviennent visibles qu'après publication de nouveaux fichiers (puis actualisation de la page avec F5).
- Le site statique ne constitue pas un diagnostic d'appareil réel.

Le projet complet reste uniquement sur le disque D: du PC Maître ; ce dépôt contient uniquement les éléments nécessaires à l'aperçu public.
